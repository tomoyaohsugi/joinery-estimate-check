# 建具工事 見積前チェック・図面解析システム Ver.1

建築図面PDFから建具符号、寸法、数量、仕様候補を抽出し、見積前の不足情報と図面内差異を整理するStreamlit MVPです。

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 操作

1. 案件名を入力
2. 建築図面PDFをアップロード
3. 「解析開始」を押す
4. 黄色・赤の項目を確認
5. Excel報告書をダウンロード

## Ver.1の制約

- 文字情報を持つPDFが主対象です。
- スキャン画像PDFはOCR追加が必要です。
- 図形だけで表現された建具の自動数量カウントは対象外です。
- 読取結果は見積前確認支援用であり、製品適合、製作寸法、施工可否を確定しません。
